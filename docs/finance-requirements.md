# 理财模块 · 需求开发文档

> 依据：[finance-module-design.md](finance-module-design.md)（已确认）。
> 技术实现细节见 [finance-dev-plan.md](finance-dev-plan.md)；本文给出需求、验收标准与数据字典，作为开发与验收的唯一功能基线。

---

## 1. 范围

**本期范围（M2a + M2b）**：家庭成员管理、资产/负债登记（12 类预置分类）、资产台账、资产详情、附件归档、到期提醒、到期日历、总览看板。

**明确排除（后续版本）**：收益分析（M3）、房贷/信用卡模板增强（M3）、导入导出（M3）、自动行情、多币种、收支流水记账、分类自定义新建。

## 2. 用户与场景

- **角色**：家庭记账人（当前单机免登录；M4 后为家庭成员账号）。
- **场景 1**：登记一笔 3 年期银行定期（银行、50,000 元、2.6%），系统自动算出到期本息 53,900，到期前 7 天在总览与日历出现橙色提醒。
- **场景 2**：借给王五 20,000 元（无息、约定 11-02 归还），上传借据照片归档；到期未还在台账标红，还款后"登记还款"留痕。
- **场景 3**：打开总览查看净资产、资产分布（按分类/按成员两个视角）与近一年趋势曲线。

## 3. 功能需求（FR）

优先级：P0 = M2a 必须交付；P1 = M2b 必须交付。

### FR-01 家庭成员管理（P0）
- 提供成员字典（姓名、备注）；系统预置"本人"且不可删除；成员可停用，停用后不可作为新资产归属人。
- 入口：台账工具栏"成员管理"弹窗、新增弹窗下拉"＋ 新建成员"。
- **验收标准**：① 新建"配偶"后，新增资产归属人下拉出现"配偶"；② 停用"配偶"后，新增资产选不到"配偶"，但已有记录保留并正常展示；③ "本人"无删除按钮。

### FR-02 资产/负债登记（P0）
- 支持 12 类预置分类的新增与编辑；表单按分类动态渲染模板字段（设计 §4.3/§2.2 模板）。
- 必填：方向、分类、名称、金额、归属人；模板级必填按分类（如定期必须存入/到期日期与年利率）。
- 弹窗内实时展示自动计算结果（期限/到期利息/到期本息/预计收益等，公式同服务端）。
- **验收标准**：① 12 类各成功登记 1 条；② 定期表单录入 50,000 元、2.6%、36 个月，弹窗实时显示到期利息 ¥3,900、本息 ¥53,900；③ 缺必填项保存时逐项标红并定位；④ 方向选"负债"时分类列表只显示负债类。

### FR-03 资产台账（P0）
- 左栏分类树（含记录数），右侧按分类分组的表格（小计金额）；工具栏：关键字搜索（名称/机构）、归属人筛选、状态筛选、成员管理、新增。
- 行内显示：名称（含归属人小标签）、机构/交易对手、金额、利率、到期日、状态、附件标记；即将到期（黄）/紧急（橙）/逾期（红）行内着色。
- 外借与负债金额列语义为**未还金额**；行点击进入详情；支持软删除（删除需二次确认）。
- **验收标准**：① 按分类/归属人/状态筛选结果正确，分类小计与筛选后合计一致；② 一笔 11-02 到期未还的外借行显示红色逾期并展示逾期天数；③ 删除后列表消失，重进不出现。

### FR-04 资产详情（P1）
- 顶部关键数字条（按分类的 computed 结果）；基本信息（含归属人）；市值历史曲线；附件区；操作日志。
- 操作按钮：编辑、状态流转（按分类出现 支取/续存/登记还款/结清）、删除。
- **验收标准**：① 定期详情显示期限/利息/本息与剩余天数，且与列表弹窗预览一致；② 外借详情显示借款人、还款方式、已还/未还汇总、还款流水（来自操作日志）；③ 每次操作（创建/编辑/流转/上传/市值更新）都在操作日志出现一条含时间与摘要的记录。

### FR-05 附件归档（P1）
- 资产级附件：上传（借据/存单/合同扫描件）、下载、删除；支持多文件；列表与详情可见 📎 标记。
- 限制：单文件 ≤10 MB；类型限 jpg/jpeg/png/webp/heic/pdf；单资产 ≤20 个。
- **验收标准**：① 上传 5MB jpg 成功并在详情可预览文件名、可下载且文件名正确；② 上传 exe / 11MB 文件被拒绝并 Toast 提示原因；③ 删除附件后文件不可再下载。

### FR-06 到期与三级提醒（P1）
- 有效状态派生：逾期（红，仅借贷类）/ 已到期待处理（橙红）/ 紧急 ≤7 天（橙）/ 预告 ≤30 天（黄）。
- 呈现位置：总览"近期到期提醒"、台账行内着色、到期日历分组。
- **验收标准**：① 分别构造 0/3/10/40 天后到期的资产，四处呈现的级别均正确；② 已结清/已支取资产不再出现在提醒中。

### FR-07 到期日历（P1）
- 列表视图按三级分组，日历视图按月历网格显示当月到期分布；可按月切换。
- 行内直接操作：续存 / 支取 / 登记还款 / 标记已还 / 提醒（仅本地视觉）。
- **验收标准**：① 月历视图中 10-18 的格子出现"工行定期 ¥53,900"角标且点击进入该日列表；② 从日历"登记还款 ¥5,000"后，该到期项从未还列表金额更新、操作日志留痕。

### FR-08 总览看板（P0）
- 四 StatCard：总资产 / 总负债 / 净资产（含较上月变化）/ 未来 30 天到期（笔数+金额+最早日期，点击进日历）。
- 资产分布环形图：支持 **按分类 | 按成员** 切换；负债灰色系；扇区点击进台账并带筛选。
- 净资产趋势折线图：默认近 12 个月，支持 全部/近1年 切换；无数据时显示空态引导。
- **验收标准**：① 卡片数值 = 台账各分组合计（含负债为减项），与筛选结果可对账；② 按成员视图正确显示"本人/配偶"等份额；③ 趋势图在仅有本月数据时显示单点 + 空态说明，不报错。

### FR-09 状态流转（P1）
- `持有中 → 已支取/已续存/已还清/已结清`（手动）；登记还款可多次、部分还款合法。
- 流转后：列表/看板金额随之退出合计（已结清不再计入总资产/负债），操作日志留痕。
- **验收标准**：① 外借 20,000 分两次各还 10,000 后，未还=0 且提示可结清；结清后总资产减 20,000；② 定期"续存"后生成一条新持有记录（复制基本信息、起息=原到期日），原记录标记"已续存"。

### FR-10 市值历史（P1）
- 贵金属/股票/活期等可"手动更新市值"：记一条 `(日期, 价值)` 快照并更新当前金额；详情页展示历史曲线。
- 总览趋势 = 各资产月末价值汇总；新增记录后曲线即时反映。
- **验收标准**：① 更新活期余额 12,000 后，台账金额、总览合计、趋势末端三点一致；② 历史曲线按时间升序显示全部快照点。

## 6. 数据字典（摘要，完整 DDL 见开发方案 §2）

### 6.1 finance_assets（核心实体）

| 字段 | 类型 | 约束/说明 |
| --- | --- | --- |
| name | TEXT | 必填，≤100 字 |
| direction | TEXT | asset / liability |
| category | TEXT | 预置分类 code，方向须一致 |
| holder_member_id | INTEGER | 归属人，必填，引用 finance_members |
| institution | TEXT | 银行/发行机构/借款人/债权人 |
| amount_cents | INTEGER | >0；定期=本金、活期=余额、股票=市值、外借=借款总额、房贷=剩余本金 |
| start_date / end_date | TEXT | YYYY-MM-DD，可空；end ≥ start |
| annual_rate | REAL | 年利率 %，NULL=无息/不适用 |
| status / settle_action / settled_at | TEXT | holding/settled；withdraw/renew/repay/clear |
| extra | TEXT(JSON) | 分类专属字段（开发方案 §2.2 键位） |
| is_deleted / user_id | INTEGER | 软删除；M4 行级预留 |

### 6.2 派生与统计口径

- **总资产** = Σ(方向=asset，状态=holding，未删除)；**总负债** = Σ(方向=liability，同口径)；**净资产** = 总资产 − 总负债。
- **未还金额**（外借/外债/信用卡）= amount_cents − Σ(还款事件)。
- **到期金额**：定期/理财 = 到期本息/预计到期值；借贷 = 未还金额。
- 已结清/已支取记录仅存于台账（筛选可见），不再计入任何看板合计。

## 7. 边界与异常场景

| 场景 | 预期行为 |
| --- | --- |
| 外借无息（利率留空） | 合法；详情不显示利率项 |
| 部分还款后修改原金额 | 允许；未还=新金额−已还，若已还>新金额给出提示 |
| 提前支取定期 | 结清动作选"支取"并填写实际金额；原记录退出合计 |
| 归属人被停用 | 历史记录不受影响；筛选器仍可按其筛选 |
| 附件随资产软删除 | 详情不可达（4004），文件保留于磁盘（保守不清除） |
| 无任何资产 | 总览四卡片显示 ¥0 与空态引导"登记第一笔资产" |
| 大金额（亿元级） | 金额分存储上限 10^13 分（约 1 亿亿元），表单校验上限并提示 |
