# 家庭助手 FamilyAssistant — 整体 UI 设计规范

| 项目 | 内容 |
| --- | --- |
| 版本 | v0.1（M0 评审稿） |
| 日期 | 2026-10-14 |
| 适用范围 | frontend/ 全部页面（理财 / 选房 / 选车 / 备忘录 / 文件存档 / 总览） |
| 设计约束 | 与架构约束一致：**零构建、无外部 UI 库/图标库/字体库、离线可用**；仅原生 HTML/CSS/JS + 内联 SVG |

---

## 1. 设计目标与原则

1. **清晰易读**：家庭场景多在小屏笔记本/平板上使用，信息密度适中、字号偏大、对比度达 WCAG AA。
2. **零构建实现**：所有组件（弹窗/图表/图标/提示）用原生技术实现，禁止引入 CDN、字体、图标库、图表库。
3. **一致性与可扩展**：全部样式收敛到设计令牌（CSS 变量），新模块页面只允许组合既有组件。
4. **模块主题色**：五个业务模块各有标识色，用于导航、页面徽标、模块内强调元素，增强空间方位感。
5. **移动可用**：768px 以下单列布局，导航折叠为顶栏，表格降级为卡片列表（M1 后逐步实现）。

- 侧边栏：模块色小圆点置于导航项左侧；选中项填充对应**模块主题色**（不再是统一蓝色）。

- 暗色模式（预留 M5+）：所有颜色经 CSS 变量映射，未来用 `[data-theme="dark"]` 整体覆盖，不改动组件代码。

## 4. 组件规范

> 类名约定：新组件统一 `fa-` 前缀 + BEM 变体（如 `.fa-btn` `.fa-btn--primary`）；现有壳上的简单类名（card/nav/table 等）保持不变。

### 4.1 按钮 `.fa-btn`

| 变体 | 样式 | 用途 |
| --- | --- | --- |
| `--primary` | 主色实底、白字 | 每页最多 1 个（主操作：记一笔/新增候选/上传文件） |
| `--secondary` | 白底、灰描边 | 次操作（取消、筛选） |
| `--danger` | 危险色实底 | 删除等破坏性操作 |
| `--ghost` | 无底、主色字 | 行内轻量操作（"对比""查看全部"） |

- 尺寸：`sm` 高 28px / 默认高 34px；内边距 0 12px / 0 16px。
- 状态：hover 提亮一档；disabled `opacity .5`；loading 前置 CSS 旋转图标并禁点。
- 仅图标按钮（表格行内编辑/删除）：24×24，必须带 `aria-label`。

### 4.2 表单控件

- Label 位于输入框上方，13px；必填项 Label 前红 `*`。
- Input/Select/Textarea：高 34px，圆角 8px，边框 `#d1d5ba`（灰）；focus 时主色边框 + 3px `rgba(37,99,235,.15)` 光环。
- 校验失败：危险色边框，下方 12px 红色提示文字；日期时间使用**原生** `<input type="date">` / `<input type="datetime-local">`。
- 静态说明文字用 `--text-muted`。

### 4.3 弹窗 `.fa-modal`（原生 `<dialog>`）

- 底层遮罩 `rgba(15,23,42,.45)`，弹窗白底圆角 12px、阴影 `--shadow-2`。
- 宽度档位：`sm` 400px（确认删除）/ `md` 560px（新增备忘、记账）/ `lg` 720px（房源/车型录入）。
- 结构：标题栏（15px/600 + 关闭×）→ 表单区（内边距 24px，两列栅格，见 5.x）→ 底部操作栏（右对齐：取消 + 主按钮）。
- 交互：Esc / 点击遮罩可关闭；**破坏性确认**标题用危险色；主表单打开时焦点进入第一个输入框。

### 4.4 表格 `.table`（沿用现有）

- 表头灰底 13px/600；行 hover 浅灰 `#f9fafb`；行尾"操作"列放图标按钮（编辑/删除），白空间按 8px。
- 空状态交给 `EmptyState`（4.8）；加载中显示 3 行骨架条（CSS 渐变扫光动画）。

### 4.5 标签 `.fa-tag`

| 语义 | 配色 | 示例 |
| --- | --- | --- |
| 进行中 | `--primary-soft` 底/主色字 | 备忘"进行中"、房源"看房中" |
| 已完成/已选定/收入 | `--ok-soft` 底/绿字 | |
| 临近截止/试驾中 | `--warn-soft` 底/琥珀字 | 备忘 24h 内到期 |
| 已放弃/已过期 | 灰底 `#f1f5f9`/灰字 | |
| 高优先级 | `--err-soft` 底/红字 | |

尺寸：高 22px、圆角 `--radius-full`、12px 字。

### 4.6 StatCard `.fa-stat`（理财/总览用）

```
┌──────────────┐
│ 本月支出  13px │
│ ¥ 12,480  ↑8% │  ← 数值 24px tabular-nums；环比小箭头
└──────────────┘
```
白卡片 + 左侧 4px 模块色条；金额千分位；收入绿箭头/支出红箭头。

### 4.7 Toast `.fa-toast`（全局反馈）

- 位置：右下角 `fixed`，`z-index: 200`；左侧 4px 语义色条。
- 类型：success / error / info；内容一行（"已删除备忘"）；2.5s 自动消失，悬停暂停；最多同时 3 条。

### 4.8 EmptyState（沿用并升级）

- 结构：模块专属内联 SVG 小图（空钱包/空房子/空车库/空便签/空文件夹）+ 主文案 + 引导主按钮（"记第一笔账"）。
- 已有 `ui.js emptyState()` 基础上扩展图标参数。

### 4.9 图标体系（零依赖核心）

- `assets/js/icons.js`：`icon(name, size=16)` 返回内联 SVG 字符串；`stroke: currentColor, stroke-width: 1.5, linecap: round`。
- 首批清单（16 个）：钱包、房子、汽车、便签、文件夹（导航）；加号、搜索、编辑、删除、上传、下载、筛选、关闭、勾选、日历、警告（操作）。
- 导航图标颜色继承模块主题色。

### 4.10 图表方案（原生 SVG/CSS，M2 理财起用）

| 图表 | 实现 | 用途 |
| --- | --- | --- |
| 环形占比图 | SVG `circle` + `stroke-dasharray` | 支出分类占比 |
| 柱状图 | flex 容器 + 高度百分比 div | 近 6 月收支对比 |
| 评分条 | 底槽 div + 宽度百分比填充 | 选房/选车加权评分 |

## 6. 全局状态与反馈约定

| 状态 | 表现 |
| --- | --- |
| 加载中 | 表格 3 行骨架屏；按钮 loading 禁点 |
| 空数据 | EmptyState + 引导按钮（4.8） |
| 请求失败 | 页面顶部 `banner.error` + 重试按钮；操作失败用 error Toast |
| 操作成功 | success Toast（删除/保存/上传完成） |
| 无权限/未认证(M4) | 跳登录页（预留路由 `#/login`） |

## 7. 可访问性与文案

- 焦点可见：`:focus-visible` 2px 主色外轮廓；弹窗内 Tab 循环（简化陷阱）。
- 对比度：正文与背景 ≥ 4.5:1（上表色板已按 AA 校验）；图标按钮必带 `aria-label`。
- 文案规范：按钮动词开头（新增/保存/删除）；删除确认写明对象（"删除备忘「交物业费」？"）；相对时间（刚刚/x 分钟前/昨天/10-12）；金额 `¥` + 千分位。

## 8. CSS 组织与落地顺序

- 现阶段单文件 `main.css` 按"令牌 → 基础 → 布局 → 组件 → 模块"注释分段；超过 ~600 行后拆为 `tokens.css / base.css / components.css / modules.css`，`index.html` 按序引入（仍零构建）。
- 组件 JS 落地于 `ui.js`（el/card/table 已有，扩展 modal/toast/tag/stat/button）；图标集中于新增 `icons.js`。

**实施排期**：M1 需组件 = 表单/弹窗/Toast/标签/上传进度/EmptyState 图标（备忘录 + 文件存档）；M2 = StatCard + 原生图表；M3 = 候选卡片流 + 对比矩阵 + 评分条；总览页与暗色模式放 M5。
